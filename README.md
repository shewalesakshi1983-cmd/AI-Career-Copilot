# AI Career Copilot

AI-powered Resume Analyzer built with Flask and Groq AI.

## Features

- ATS Score Analysis
- Skill Extraction
- Missing Skills Detection
- JD Match Score
- Career Roadmap Generator
- Interview Questions Generator
- Resume Tips
- PDF Report Download
- Resume History
- AI Career Assistant
- Mock Test (20 Questions)

## Tech Stack

- Flask
- SQLAlchemy
- Groq AI
- PyPDF2
- python-docx
- Pillow
- pytesseract
- ReportLab
- MySQL (TiDB)

## Run Project

```bash
pip install -r requirements.txt
python app.py
